# Agent Model Badge privacy policy

Effective 7 October 2026.

Agent Model Badge is a Claude Code plugin that labels each subagent with the model and effort it runs on. It runs entirely on your own machine.

- **What it reads:** the model and effort each Agent call asks for, the model and effort of each request, and Claude Code's list of running agents, to match each subagent to its call.
- **What it stores:** nothing. Its labels live in memory for the current session only, and it writes no files.
- **What it sends:** nothing. It makes no network requests and collects no analytics.

It is not intended for people under 18.

Questions: open an issue at <https://github.com/New-Retr0/claude-dock/issues>.
